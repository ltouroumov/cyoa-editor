# V1 Format (Viewer)

The V1 format is the production format used by the viewer for compatibility with the MeanDelay iCYOA ecosystem.

## Structure

```json
{
  "activated": [],
  "backpack": [],
  "groups": [],
  "pointTypes": [],
  "rows": [],
  "styling": {},
  "variables": []
}
```

## Hierarchy

```bash
Project
├── activated[]             # IDs of selected objects
├── backpack[]              # Backpack items (same structure as rows)
├── groups[]                # Groups of rows
│   ├── id
│   ├── name
│   └── elements[]          # Row IDs in this group
├── pointTypes[]            # Point type definitions
│   ├── id
│   ├── name
│   ├── startingSum
│   ├── activatedId
│   ├── beforeText
│   ├── afterText
│   ├── iconHeight
│   ├── iconWidth
│   ├── iconIsOn
│   ├── image
│   └── imageOnSide
├── rows[]                  # Main content rows
│   ├── id
│   ├── title
│   ├── titleText
│   ├── image
│   ├── imageIsUrl
│   ├── imageLink
│   ├── objectWidth
│   ├── isButtonRow
│   ├── isInfoRow
│   ├── isPrivateStyling
│   ├── isResultRow
│   ├── allowedChoices
│   ├── requireds[]        # Row-level conditions
│   ├── objects[]          # Choices in this row
│   │   ├── id
│   │   ├── title
│   │   ├── text
│   │   ├── image
│   │   ├── imageIsUrl
│   │   ├── imageLink
│   │   ├── objectWidth
│   │   ├── isVisible
│   │   ├── isNotSelectable
│   │   ├── isSelectableMultiple
│   │   ├── activatesOtherChoice
│   │   ├── activateOtherChoice
│   │   ├── deactivateOtherChoice
│   │   ├── deactivateThisChoice
│   │   ├── activateThisChoice
│   │   ├── template
│   │   ├── scores[]       # Point modifications
│   │   │   ├── id
│   │   │   ├── value
│   │   │   ├── beforeText
│   │   │   ├── afterText
│   │   │   ├── showScore
│   │   │   └── requireds[]
│   │   ├── addons[]        # Sub-items
│   │   └── requireds[]    # Choice-level conditions
│   └── styling             # Row-specific styling
└── styling                 # Global style settings
    ├── rowTitle, rowText, etc.
    ├── objectTitle, objectText, etc.
    ├── addonTitle, addonText, etc.
    └── ... (various CSS/Layout properties)
```

## Width Classes

V1 uses Bootstrap column classes that map to a 60-column grid:

| Class      | Width (of 60)   |
|------------|-----------------|
| `col-12`   | 60 (full width) |
| `col-sm-6` | 30 (half)       |
| `col-md-4` | 20 (third)      |
| `col-md-3` | 15 (quarter)    |
| `col-lg-2` | 10 (sixth)      |
| `col-xl-1` | 5 (twelfth)     |

## Condition Terms

Requirements use a nested structure:

```json5
{
  "requireds": [
    {
      "type": "id",
      // "id", "or", "points", "pointCompare"
      "required": true,
      // true = required, false = incompatible
      "reqId": "choice-id",
      // Primary ID
      "reqId1": "",
      // Additional ID (for type: "pointCompare")
      "reqId2": "",
      // Additional ID (for type: "pointCompare")
      "reqId3": "",
      // Additional ID (for type: "pointCompare")
      "reqPoints": 0,
      // Number of points (for type: "points")
      "operator": 1,
      // 1: >, 2: >=, 3: ==, 4: <=, 5: <
      "orRequired": [
        // For type: "or"
        {
          "req": "choice-a"
        },
        {
          "req": "choice-b"
        }
      ],
      "showRequired": true,
      "requireds": []
      // Nested conditions (AND)
    }
  ]
}
```
